# Penjaga Terumbu – Misi Menyelamatkan Karang

## Deskripsi Proyek
Penjaga Terumbu merupakan aplikasi animasi 2D interaktif bertema kehidupan bawah laut yang dibuat menggunakan Python dan Pygame. Pemain mengendalikan kura-kura untuk mengumpulkan sampah dan membantu menjaga kebersihan terumbu karang.

## Tujuan
Menerapkan konsep grafika komputer dalam pembuatan objek, transformasi, dan animasi 2D melalui sebuah permainan sederhana.

## Konsep Grafika Komputer
Konsep yang diterapkan dalam proyek ini meliputi:
- Sistem koordinat dan objek 2D.
- Algoritma garis Bresenham.
- Algoritma lingkaran Midpoint.
- Pemodelan objek menggunakan bentuk geometris dan poligon.
- Transformasi geometri 2D.
- Animasi 2D.
- Layering dan komposisi scene.

## Transformasi dan Animasi
- **Translasi:** menggerakkan kura-kura menggunakan keyboard dan menggerakkan objek lainnya.
- **Rotasi:** memutar objek ikan.
- **Scaling:** mengubah ukuran objek dan menampilkan pertumbuhan terumbu karang.
- **Animasi:** menggerakkan objek dengan pengaturan FPS.

## Library yang Digunakan
- Python
- Pygame
- Math
- Random

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Instal Pygame dengan perintah `pip install pygame`.
3. Buka terminal pada folder proyek.
4. Jalankan program dengan perintah `python main.py`.
